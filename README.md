## 📌 Featured Projects

### 🛒 Super Benfica — Supermarket Management Ecosystem

A complete multi-branch supermarket platform: one API serving a web admin panel, an online store and a mobile app, all synced in real time.

| Project | Description | Stack |
| ------- | ----------- | ----- |
| [superbenfica-api](https://github.com/trobozoi/superbenfica-api) | REST + WebSocket API: multi-branch inventory, barcode catalog, orders, picking checklist, real-time notifications, rate limiting, async tasks and cached reports | Django 5.2 · DRF · JWT · Channels · Celery · Redis · PostgreSQL |
| [superbenfica-admin](https://github.com/trobozoi/superbenfica-admin) | Admin dashboard with KPIs, orders, picking queue with barcode scanner, stock, customers, reports and role-based permissions | Next.js 16 · React 19 · TypeScript · Tailwind · TanStack Query · Recharts |
| [superbenfica-web](https://github.com/trobozoi/superbenfica-web) | Customer online store: catalog, cart, in-store pickup checkout and live order tracking | Next.js 16 · React 19 · TypeScript · Zustand · Playwright |
| [superbenfica-mobile](https://github.com/trobozoi/superbenfica-mobile) | iOS/Android customer app with real-time order tracking, push notifications, offline mode and dark theme | Expo · React Native · TypeScript · Redux Toolkit |
